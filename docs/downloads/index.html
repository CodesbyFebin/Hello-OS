Start with Compose

git clone https://github.com/CodesbyFebin/Hello-OS.git
cd Hello-OS
docker compose up --build

Then visit http://localhost:3000. Review the installation guide and project README.

Release policy

Native packages will be listed only after the project has a reproducible build, versioned release, supported platform/architecture list, artifact integrity checks, and clear signing information. Do not download unofficial binaries that claim to be an official HELLO OS build.
