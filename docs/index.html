A local-first agent workspace

Give agents a place to work.

HELLO OS is an open-source agentic operating system prototype for identity, memory, tools, missions, and inspectable activity. Run the dashboard and MCP service on your own machine with Docker Compose.

Start with DockerExplore the source

Prototype status: native APK, EXE/PEXE, and DEB installers are not published. The supported path is a self-hosted Docker deployment.

One workspace, several agent primitives

Identity

Prototype Ed25519 identities and did:key identifiers, with a soul record and wallet entry.

Memory

CORE, RECALL, and ARCHIVE tiers with expiry, valid-time filters, and retrieval budgets.

Tools

An MCP-compatible JSON-RPC service with forge, cortex, memory, and checkpoint tools.

Tasks

An agent card and A2A-style task methods for sending, listing, updating, and cancelling work.

Run it yourself

Install Docker Engine and Docker Compose, then clone the repository and start the app. The browser dashboard runs locally; the MCP service is available on port 3030.

git clone https://github.com/CodesbyFebin/Hello-OS.git
cd Hello-OS
docker compose up --build

Open http://localhost:3000. Read the full setup guide for source development, configuration, data storage, and safe shutdown instructions.

Built for exploration, documented with boundaries

HELLO OS is an experimental local-first agent runtime, not a hardened production control plane. The demo server stores private signing keys; use managed key custody and a security review before production use. The project does not claim full protocol conformance, real payments, or guaranteed crawl and search ranking.
