# HELLO OS

> HELLO OS is an experimental, local-first agentic OS prototype with agent identity, persistent memory, missions, an MCP-compatible tool service, A2A-style tasks, and a human dashboard.

## Verified implementation facts
- The application uses Next.js, React, TypeScript, Prisma, and SQLite; Docker Compose runs the dashboard and a separate MCP service.
- The MCP endpoint is /mcp. Selected tools include forge, cortex, tiered memory, and checkpoint.
- Agent discovery is available at /.well-known/agent-card.json.
- A2A-style JSON-RPC supports message/send and task lifecycle methods.
- AML v1 statically parses and validates declarations at POST /api/aml/compile and POST /api/aml/validate. It builds a deterministic intent graph and hashes source; it never executes AML or invokes tools.
- Evolution Lab stores seeded optimization runs over synthetic vectors. Its proxy scores are not model training or agent benchmarks.
- HELLO EVOLVE is a browser simulation using synthetic demo data.
- The repository is licensed under MIT; see LICENSE.
- GitHub Pages hosts static documentation only; it does not run the Next.js APIs, SQLite database, or MCP service.
- APK, Windows EXE/PEXE, and DEB installers are not currently published.

## Integration catalog status
The catalog contains 100 proposed connector targets and 50 design patterns for legacy bridges. Every connector is marked unconnected and every pattern unshipped. These records are roadmap references, not integrations or vendor endorsements. The running prototype exposes only the capabilities documented in the repository.

## Security and capability limits
This is an experimental prototype, not a hardened production control plane. Demo private keys are stored by the server and are not production-grade key custody. The project does not claim full MCP/A2A conformance, OAuth, SSE, production multi-tenancy, tamper-proof auditing, real-money payments, or Firecracker microVM checkpoints. Wallet balances are prototype credits. No crawler ping, sitemap, or metadata can guarantee search indexing or ranking.

## Start locally
Clone the repository and run docker compose up --build. Open http://localhost:3000. See README.md for prerequisites, configuration, and data handling.
