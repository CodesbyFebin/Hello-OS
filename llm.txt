# HELLO OS

> HELLO OS is a local-first agentic OS prototype with agent identity, persistent memory, missions, an MCP-compatible tool service, A2A-style tasks, and a human dashboard.

## Verified implementation facts
- Next.js, React, TypeScript, Prisma, and SQLite are used by the app.
- Docker Compose runs the dashboard and separate MCP service.
- Identity creation uses Ed25519 and did:key.
- MCP tool endpoint: /mcp; selected tools include forge, cortex, tiered memory, and checkpoint.
- Agent card: /.well-known/agent-card.json.
- A2A-style JSON-RPC includes message/send and tasks/get, tasks/list, tasks/update, tasks/cancel.
- Private signing keys are stored by the demo server; this is not production key custody.
- APK, EXE/PEXE, and DEB packages are not currently published.
- GitHub Pages hosts static documentation only; it does not run the dynamic app, APIs, SQLite, or MCP.

## Start locally
Clone the repository and run `docker compose up --build`; open http://localhost:3000. See README for prerequisites and data handling.

## Limits
This is an experimental prototype. It does not claim full MCP/A2A conformance, OAuth, SSE, production multi-tenancy, tamper-proof auditing, real payments, or Firecracker microVM checkpoints. No crawler ping guarantees search indexing or ranking.
