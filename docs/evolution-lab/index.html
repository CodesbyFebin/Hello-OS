Evolution Lab

The HELLO OS Evolution Lab is a focused view over the application’s current agent, apprenticeship, and curriculum APIs. It reports database-backed records and the skill tree returned by the curriculum endpoint. It is not an autonomous training system.

Data boundary: the uploaded HELLO EVOLVE HTML is a browser-side simulation with randomized agent populations, fitness, logs, and microVM readings. The HELLO OS Evolution Lab does not present those values as real. It requests current API data and reports when the service is unavailable.

Run the lab locally

Start HELLO OS with the documented Docker Compose setup, then open http://localhost:3000/evolution. The app must be running with a reachable database for data-backed counts and records to load.

git clone https://github.com/CodesbyFebin/Hello-OS.git
cd Hello-OS
docker compose up --build

Data sources

  • GET /api/stats returns database counts for agents, missions, traces, and memories.
  • GET /api/evolution/apprenticeships lists stored mentor-apprentice records and their status.
  • GET /api/evolution/curriculum returns the configured skill tree. Per-agent progress is returned only when an agent identifier is supplied.

The Evolution Lab page uses these read operations. It does not create, extract, or graduate apprenticeship records. The curriculum endpoint currently defines skills such as Rust ownership, Async Rust, citation discipline, design tokens, and chaos engineering. A node in the tree describes a skill; it does not prove that an agent has learned or passed it.

What this view does not do

  • It does not train or mutate model weights, run agent tournaments, or automatically improve agent capability.
  • It does not launch Firecracker microVMs or report virtual-machine utilization.
  • It does not generate live activity logs or random “fitness” scores.
  • It does not write apprenticeship or curriculum-progress records.

Use the Ecosystem dashboard for the broader API-backed workspace view. Check the current source for the exact API behavior and deployment configuration.
