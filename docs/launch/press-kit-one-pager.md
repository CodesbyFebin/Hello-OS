# HELLO OS press kit

**One-line description:** HELLO OS is an open-source, local-first prototype for inspecting agent identities, missions, memory, selected MCP interactions, and statically compiled intent graphs.

## Project facts

- **Project:** HELLO OS
- **Maintainer:** Febin Francis, CodesbyFebin
- **Source:** https://github.com/CodesbyFebin/Hello-OS
- **Downloads:** https://codesbyfebin.github.io/Hello-OS/downloads/
- **License:** MIT
- **Stack:** Next.js, TypeScript, Prisma, SQLite, Bun MCP service
- **Maturity:** Local-first prototype; not production multi-tenant infrastructure

## What it does today

The repository provides a dashboard and APIs for inspecting supported local records, a local MCP service, protocol documentation, and a static AML compiler/validator. AML source is parsed into a graph with diagnostics; it is never executed. The project includes Docker Compose setup and tests for selected public-site and compiler behavior.

## What it does not do

There is no hosted model inference, production authentication, tenant isolation, on-chain wallet settlement, microVM execution, or production cloud service. Dashboard showcase artwork and the EVOLVE view contain synthetic/simulation content. Internal credit values are not money.
